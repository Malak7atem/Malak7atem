## 🔬 Research & Selected Projects

### 1. Medical Imaging & Ovarian Tumor Classification
**MIRASOL 2026 Workshop — Accepted Research Paper**

Co-authored research on improving ovarian tumor classification from ultrasound images through:
- Segmentation-guided image preprocessing and artifact removal.
- Deep learning-based image classification.
- Class imbalance handling and model optimization.

*Technologies: Python, Deep Learning, U-Net, LaMa, EfficientNet-B2.*

### 2. AI-Guided Ultrasound Training System
**Graduation Project — A+ | 1st Place, Nile University Graduation Projects Competition**

Developed an AI-guided ultrasound training system combining patient-specific anatomical modeling, ultrasound simulation, image enhancement, anatomical recognition, and intelligent learning guidance.

The project explores how AI can support ultrasound education and improve the learning experience.

*Technologies: Python, Medical Imaging, 3D Slicer, U-Net++, EfficientNet-B3, Computer Vision.*

### 3. Computational Biology & Gene Expression Analysis

Explored gene expression data analysis for pancreatic cancer using TCGA datasets.

Work included:
- Differential gene expression analysis.
- Statistical analysis and dimensionality reduction.
- Clustering and survival analysis.
- Functional enrichment and pathway analysis.

*Technologies: R, limma, clusterProfiler, PCA, K-means, Kaplan–Meier Analysis.*
